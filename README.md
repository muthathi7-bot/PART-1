*Part:* 1 - Building the Foundation  

## Project Overview
This project is a 5-page static HTML website for a fictional construction company called Muthathi Constructions (Pty) Ltd. The website serves as a portfolio and lead-generation tool for potential clients including homeowners, developers, and businesses. It focuses on semantic HTML5 structure, proper file organisation, and accessibility.

## Website Goals and Objectives
- Establish a professional online presence for the company.
- Showcase services and completed construction projects.
- Generate business leads through a "Request a Quote" contact form.
- Demonstrate proficiency in HTML5, semantic elements, and proper internal linking.

## Key Features and Functionality
- 5 fully linked HTML pages (index, about, services, projects, contact).
- Semantic HTML5 elements (<header>, <nav>, <main>, <section>, <article>, <footer>).
- Single, horizontal main navigation menu (using pure HTML inline tags).
- Exactly 6 placeholder images with descriptive alt text.
- Accessible web forms using <label>, proper input types, a submit button, and a reset button.
- Embedded Google Maps <iframe> demonstrating location functionality.

## Timeline and Milestones
- *Week 1-2:* Project planning, content research, and gathering assets.
- *Week 3-4:* Development of HTML5 structure and content integration for all 5 pages.
- *Week 5-6:* Final testing, internal linking checks, documentation, and submission.
